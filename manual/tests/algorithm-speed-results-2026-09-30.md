# 種別選択・行動候補の高速化（2026-09-30）

変更前のHEADと変更後をApple clang 21.0.0、C++17、`-O2 -pthread`でビルドして比較した。計測中は他のビルド・テストを実行せず、変更後の探索、変更前の探索、変更前の種別選択、変更後の種別選択の順で実行した。各条件1回の計測で、速度は環境によって変動する。

## 変更内容

- 探索の行動候補から`GameState`を取り除き、`PendingAction`と評価・経路情報だけをソートする。評価用状態は親ごとに1回コピーし、候補ごとに対象車の予約だけを差し替える。採用した予約を子状態に反映する。
- 行動候補配列と選択肢配列の確保領域を探索中に再利用する。
- 種別選択の開始位置ごとの巡回能力を、配置列挙の外で事前計算する。
- 同じ種別配置の交通シナリオについて、直前のシナリオと初日から連続して同じ交通条件の日程を再利用する。以前は初日だけを再利用していた。分岐した日以降は再探索する。

候補数・探索幅・重み・合計スコア優先の比較基準は変更していない。

## 探索

```sh
.build/tools/solver_benchmark --seeds 3 --repeats 1 --fixed-work --mixed-traffic
```

8・16・24・32マス、seed 1～3、4日間、2構成の96日次回答を比較した。ツールの`baseline`と`improved`は機能構成名であり、今回の変更前後を表す名前ではない。両構成をそれぞれ変更前後で比較した。

| 機能構成 | 変更前の時間合計 | 変更後の時間合計 | 短縮率 |
|---|---:|---:|---:|
| baseline | 10,859 ms | 10,514 ms | 3.2% |
| improved | 9,939 ms | 9,593 ms | 3.5% |

全96日で得点・展開数・計画ハッシュ・キャッシュ等のカウンタが一致した。全回答が合法で、再シミュレーションした終了状態も一致した。変更前の別の計測は10,783／9,936 msだった。数％の差なので速度の評価には環境変動を含む。

## 種別選択

```sh
.build/tools/agent_selection_benchmark --size 16 --seeds 4 --selection-ms 0
```

| seed | 変更前 | 変更後 | 選択された種別 |
|---|---:|---:|---|
| 1 | 1,602 ms | 1,091 ms | SPPP |
| 2 | 996 ms | 920 ms | PPPS |
| 3 | 1,524 ms | 1,104 ms | SPPP |
| 4 | 1,733 ms | 1,008 ms | PPPS |
| 中央値 | 1,563 ms | 1,049.5 ms | 約32.9%短縮 |

Pは巡回車、Sは補給車。4件すべてで選択種別、試走候補数、シナリオ数、順調条件・未使用交通条件での再探索得点が一致した。時間制限なしの結果であり、時間制限下では省略した計算の分だけ残り日程・候補に使える時間が変わる。一般的な得点向上を保証する検証ではない。
