# `algorithm_test.cpp` の使い方

対象: [`tests/algorithm_test.cpp`](../../tests/algorithm_test.cpp)

探索で使う低レベルアルゴリズムと最適化機能の回帰テストである。

## 実行

```sh
c++ -std=c++17 -O2 -pthread -Iinc tests/algorithm_test.cpp -o /tmp/algorithm_test
/tmp/algorithm_test
```

成功時は何も表示せず終了コード0を返す。失敗時は`assert`で停止するため、`-DNDEBUG`を付けずにビルドする。

## 主な検査内容

- Dialキュー版ダイクストラと通常の優先度付きキューの距離一致
- 最小費用流と全列挙による割当コストの一致
- 最小費用流の作業領域再利用、頂点数変更、残余グラフを引き継ぐ連続実行
- 探索状態の正規化と燃料優越判定
- 時間最短経路と燃料制約付き経路の使い分け
- 移動完了前に移動元で受ける補給を含む時刻付き最短路と、貪欲ベースラインの合法性
- 混合交通の3マップ、各目的セル・燃料上限0〜6で、燃料制約付き探索を独立した使用燃料順DPと照合（到達可否、時間、最小燃料、復元経路）
- 既存の合流が成立する場合も、幅1の探索で取得を6ステップ目から4ステップ目へ早める迂回を選ぶことと、直列・並列の一致
- 障害物を考慮した合流、複数補給車、同日中の複数回補給
- 目的地到着時に燃料が尽きる巡回車への補給車移動、余裕がある場合の目的地先回り合流、目的がない補給車の不動
- 道路状態で残りステップ内に完了できない移動の除外
- マクロ経路の定期再検討を有効にした場合の複数回補給と計画の合法性
- 割当キャッシュ有効・無効・容量1・並列実行での計画一致と再利用
- 補給車の競合による巡回先の修正、通常経路から外れる合流、狭いビームでの2店取得
- 複数日試走、重み調整、エージェント種別選択の再現性
- コンソール表示の形式

このテストは小さな人工問題を使うため、`sample_maps/`には依存しない。
