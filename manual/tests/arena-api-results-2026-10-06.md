# 公開試合 API を使った経路候補保持の比較（2026-10-06）

公開 API の [`#1254`](https://procon37arena.online/api/matches/1254)、[`#860`](https://procon37arena.online/api/matches/860)、[`#864`](https://procon37arena.online/api/matches/864) から試合設定と順位を取得した。API の得点は実戦結果であり、以下のローカル得点とは交通・他チーム・種別配置が異なる。ローカル比較では両版とも同じ試合設定、補給車配置、順調交通、5秒/日を指定した。

従来の経路候補組合せは巡回車あたりの候補上限に既存計画を含めていた。上位の新経路で枠が埋まると最後の新経路を既存経路で上書きし、候補枠が1本なら改善候補が消える。既存経路を別枠で追加するよう変更した。上限を超えるのは巡回車あたり最大1本で、組合せ探索のノード上限と締切は維持する。

| 公開試合 | 実戦1位（系列/日別累計/玉） | 固定条件 | 変更前 | 変更後 |
|---|---:|---|---:|---:|
| #1254（32×32、4日） | 24/96/419 | 補給マスク17 | 24/96/383 | 24/96/384 |
| #860（24×24、7日） | 14/98/297 | 補給マスク2 | 14/98/337 | 14/98/338 |
| #864（32×32、6日） | 20/120/464 | 補給マスク17 | 20/120/285 | 20/120/283 |

再現例:

```sh
make .build/tools/arena_benchmark
.build/tools/arena_benchmark setting-1254.json 5000 17 smooth
```

ローカル得点は時間制限付き探索の単発実行であり、1〜2玉差を安定した性能差とは扱わない。#864 では玉数が2減ったため、この変更が公開盤面全体の得点を改善したとは主張しない。候補枠1本で改善案が消える不具合は独立の回帰テストで検証した。API は公開スコアと設定を提供するが、ログインなしでは各チームの行動・交通トレースを取得できない。したがって実戦の優劣や、試合の反実仮想の結果はこの比較から断定しない。
