# 8台時のエージェント種別選択（2026-09-30）

従来も8台時の補給車上限は4台であり、2台に固定してはいなかった。しかし既定12候補のうち、補給車1台など特定台数の位置違いへ候補枠が偏り、補給車2台・3台の有望配置を十分に試せない場合があった。

変更後は、最初に補給車1〜4台それぞれの距離評価最良配置と広域配置を確保する。残り4枠では補給車3台・2台の位置違いを交互に追加する。全台数を比較しながら、8台で現実的な2台・3台構成を各4配置まで試せる。

## 補給車2台・3台の固定比較

32×32、8台、8 seed、各日32ステップ、燃料上限32、全道路順調で、補給車の台数を固定して各12配置を試した。辞書順の得点は系列数、日別系列累計、玉数で比較する。

- 補給車3台は2台に5勝0同点3敗
- 系列数合計はどちらも192
- 日別系列累計は2台が506、3台が502
- 玉数は2台が597、3台が602

3台が勝つ問題の方が多い一方、日別系列累計が大きく下がる問題もある。このため8台時に3台を固定せず、2台・3台の配置を厚く比較する方式とした。

## 候補配分の変更前後

同じ8問題を種別選択5秒で比較した。変更前は補給1台が1件、2台が6件、3台が1件だった。変更後は補給2台が3件、3台が5件になった。

| 条件 | 勝/同/敗 | 系列数合計 | 日別系列累計 | 玉数 |
|---|---:|---:|---:|---:|
| 変更前 | - | 192 | 458 | 547 |
| 変更後 | 3/4/1 | 192 | 476 | 564 |

時間制限なしでは変更後の12候補で補給2台・3台を各4件選び、合計は192系列、496日別系列、602玉だった。通常生成パラメータでは燃料上限が168〜477と大きく、8件中7件で補給1台、1件で2台を選んだ。補給台数は8台という台数だけで固定せず、燃料制約と試走得点に応じて変わる。

生成問題と小さい検証用ビーム幅での比較であり、本選問題で同じ勝敗になることは保証しない。5秒制限の結果はCPU負荷で変動する。

## 実行例

```sh
.build/tools/agent_selection_benchmark --size 32 --agents 8 --seeds 8 \
  --selection-ms 0 --constrained --min-supply 2 --max-supply 2
.build/tools/agent_selection_benchmark --size 32 --agents 8 --seeds 8 \
  --selection-ms 0 --constrained --min-supply 3 --max-supply 3
.build/tools/agent_selection_benchmark --size 32 --agents 8 --seeds 8 \
  --selection-ms 5000 --constrained
```
