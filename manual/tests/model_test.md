# `model_test.cpp` の使い方

対象: [`tests/model_test.cpp`](../../tests/model_test.cpp)

競技モデルから問題生成・探索・複数日実行までを横断して確認する主要な回帰テストである。

## 実行

```sh
c++ -std=c++17 -O2 -pthread -Iinc tests/model_test.cpp -o /tmp/model_test
/tmp/model_test
```

成功時は何も表示せず終了コード0を返す。検査は`assert`を使うため、`-DNDEBUG`を付けない。

## 主な検査内容

- 六角盤面の隣接関係
- 移動、スポット取得、補給、取得順序、燃料不足判定
- 待機値の`-N`形式への圧縮
- 状態ハッシュと評価内訳
- 通常・燃料制約付きダイクストラ
- ビームサーチ、時間制限、直列・並列結果の一致
- step 1の移動反映後に行う日開始取得、巡回車の分散、補給車との合流
- スポット上での待機と翌日へ向けた補給
- エージェント種別選択、7台時の中心補給台数からの試走、探索終了ステップを含むJSON永続化、待機フォールバック
- 複数日実行とランダム問題生成

広い範囲を扱うため、個別機能を変更した場合もこのテストを最後に実行する。
