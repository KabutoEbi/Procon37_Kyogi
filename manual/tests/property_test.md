# `property_test.cpp` の使い方

対象: [`tests/property_test.cpp`](../../tests/property_test.cpp)

固定の乱数種を使い、多数の小規模入力で探索結果が独立に計算した性質を満たすか確認する。

```sh
make test-property
```

検査内容は次のとおり。

- 8×8のランダム問題128件で、復元したダイクストラ経路の終点・所要時間・燃料を再計算
- 同じ128件で`brain0Greedy`が作った1日計画を公式シミュレータで再検証
- 1次元のランダム問題256件で、時刻付き補給最短路の到達可否と最短到着時刻を独立した時間展開DPと照合

乱数種を固定しているため、失敗した入力を同じ実行で再現できる。
