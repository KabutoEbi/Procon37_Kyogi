# 本番用LAN共有フォルダの準備

## この手順で作る構成

担当1のWindows PCに共有フォルダを1個作り、担当2のWindows PCと担当3のMacからSMBで接続する。
3台のGUIには、同じ共有フォルダ内の同じ試合用フォルダを指定する。

```text
                              競技用有線LAN
                                    │
                             スイッチングHUB
                         ┌──────────┼──────────┐
                         │          │          │
                  担当1 Windows  担当2 Windows  担当3 Mac
                  共有フォルダ元    Z:で接続     SMBで接続
                  C:\ProconShare   Z:\match-01 /Volumes/ProconShare
                         └──────────┴──────────┘
                              同じmatch-01
```

この方法ではクラウド、Wi-Fi、USBメモリ、ローカルHTTPサーバーを使わない。Windows標準のファイル共有だけを使う。

## 時間がないときの最短手順

詳細は後続の章にあるが、本番直前は次の順番で進めればよい。

1. 3台をHUBへ有線接続し、Wi-Fiをオフにする。
2. 担当1 WindowsのEthernetを「プライベート」にする。
3. 担当1でネットワーク探索とファイル共有をオンにする。
4. 担当1にローカルユーザー`proconshare`を作り、パスワードを設定する。
5. `C:\ProconShare`を作り、`proconshare`へ読み取り/書き込みで共有する。
6. 担当1で`ipconfig`を実行し、EthernetのIPv4アドレスを確認する。
7. 担当2は`\\IPv4\ProconShare`、Macは`smb://IPv4/ProconShare`へ接続する。
8. 共有内に空の`match-01`を作り、3台すべてからファイルを作成・読取・削除する。
9. GUIの共有フォルダへ、担当1は`C:\ProconShare\match-01`、担当2は`Z:\match-01`、Macは`/Volumes/ProconShare/match-01`を指定する。
10. テストファイルをすべて消し、3台のGUIが同じ空フォルダを指していることを確認する。

## 準備するもの

- Windows PC 2台、Mac 1台
- 3台分の有線LANケーブル
- 必要なポート数を持つスイッチングHUB
- USB LANアダプター。LAN端子のないPCだけ必要
- 担当1 Windowsの管理者権限
- 共有専用ユーザーに設定するパスワード

共有元は担当1のWindowsとする。共有元PCがスリープ、再起動、LAN切断すると他の2台から共有できなくなるため、電源へ接続し、試合中はスリープさせない。

## 最初に決める名前

以下の名前で統一すると入力ミスが少ない。

| 用途 | この手順で使う値 |
|---|---|
| 共有元PC | 担当1のWindows |
| 共有フォルダ | `C:\ProconShare` |
| ネットワーク上の共有名 | `ProconShare` |
| 共有専用ユーザー | `proconshare` |
| 試合用フォルダ | `match-01`、`match-02`など |
| 担当2のドライブ文字 | `Z:` |

パスワードはこの文書やリポジトリへ保存しない。WindowsのPINではなく、作成した共有専用ユーザーのパスワードを使う。

## 1. 3台を有線LANへ接続する

1. 3台と競技用LANをスイッチングHUBへ接続する。
2. 3台すべてでWi-Fiをオフにする。
3. Windowsでは「設定」→「ネットワークとインターネット」→「イーサネット」を開き、接続済みになっていることを確認する。
4. Macでは「システム設定」→「ネットワーク」を開き、Ethernetが接続済みになっていることを確認する。
5. 競技サーバーへの接続が必要な場合は、3台それぞれでGUIの「通信確認（手動）」を実行する。

LANケーブルを挿しても接続済みにならない場合は、先にケーブル、HUBの電源、USB LANアダプターを確認する。

## 2. 担当1 Windowsを共有元にする

### 2-1. Ethernetをプライベートネットワークにする

1. 「設定」を開く。
2. 「ネットワークとインターネット」→「イーサネット」を開く。
3. 使用中のEthernet接続を選ぶ。
4. 「ネットワーク プロファイルの種類」を「プライベート ネットワーク」にする。

表示名はWindowsの版によって多少異なる。「パブリック」のままでは、ファイル共有がWindows Defenderファイアウォールに遮断されやすい。

### 2-2. ネットワーク探索とファイル共有を有効にする

1. 「設定」→「ネットワークとインターネット」→「ネットワークの詳細設定」を開く。
2. 「共有の詳細設定」を開く。
3. 「プライベート ネットワーク」で次の2項目をオンにする。
   - ネットワーク探索
   - ファイルとプリンターの共有
4. 「パスワード保護共有」はオンのままにする。

ファイアウォール全体を無効にしてはいけない。通常は上記設定により、プライベートネットワーク用のSMB規則が有効になる。

### 2-3. 共有専用のローカルユーザーを作る

普段使用しているMicrosoftアカウントやWindows HelloのPINはSMB認証で混乱しやすいため、共有専用ユーザーを1個作る。

1. 「設定」→「アカウント」→「その他のユーザー」を開く。
2. 「アカウントの追加」を押す。
3. 「このユーザーのサインイン情報がありません」を選ぶ。
4. 「Microsoft アカウントを持たないユーザーを追加する」を選ぶ。
5. ユーザー名を`proconshare`にする。
6. 空ではないパスワードを設定する。
7. アカウントの種類は「標準ユーザー」のままにする。

このユーザーでWindowsへサインインし直す必要はない。共有フォルダへの接続認証だけに使う。

### 2-4. 共有フォルダを作る

1. エクスプローラーで`C:\`を開く。
2. `ProconShare`フォルダを作る。
3. `C:\ProconShare`を右クリックする。
4. Windows 11では「その他のオプションを確認」を押す。
5. 「アクセスを許可する」→「特定のユーザー」を選ぶ。
6. 入力欄へ`proconshare`と入力し、「追加」を押す。
7. `proconshare`のアクセス許可レベルを「読み取り/書き込み」にする。
8. 「共有」を押し、完了する。

共有したフォルダ名が`ProconShare`なので、ネットワーク上の共有名も通常は`ProconShare`になる。

### 2-5. 共有元PC名とIPv4アドレスを控える

1. `Windows`キーを押し、`cmd`と入力して「コマンド プロンプト」を開く。
2. 次を実行する。

```bat
hostname
ipconfig
```

3. `hostname`の結果を「共有元PC名」として控える。
4. `ipconfig`では「Ethernet adapter」の「IPv4 Address」を控える。

Wi-Fi、Bluetooth、`vEthernet`、VPNのアドレスを使わない。例えばEthernetのIPv4が`192.168.10.21`なら、Windows用共有パスは次になる。

```text
\\192.168.10.21\ProconShare
```

Mac用の接続先は次になる。

```text
smb://192.168.10.21/ProconShare
```

IPv4アドレスは会場で接続し直すと変わる場合がある。当日の配線後に必ず確認し直す。

### 2-6. 担当1自身で共有を確認する

1. エクスプローラーのアドレス欄へ`\\localhost\ProconShare`と入力する。
2. `C:\ProconShare`の内容が表示されることを確認する。
3. `match-01`フォルダを作る。

この時点で開けなければ、他のPCの設定へ進まず、共有設定をやり直す。

## 3. 担当2 Windowsから接続する

### 3-1. 共有フォルダを直接開く

1. エクスプローラーを開く。
2. アドレス欄へ、担当1から聞いたパスを入力する。

```text
\\担当1のIPv4アドレス\ProconShare
```

例:

```text
\\192.168.10.21\ProconShare
```

3. 資格情報を求められたら、次を入力する。
   - ユーザー名: `担当1のPC名\proconshare`
   - パスワード: 2-3で設定したパスワード
4. `match-01`が見えることを確認する。

ユーザー名が通らない場合は、`proconshare`だけでも試せる。PINではなく共有専用ユーザーのパスワードを入力する。

### 3-2. Zドライブへ割り当てる

毎回ネットワークパスを入力しなくてよいように、共有を`Z:`へ割り当てる。

1. エクスプローラー左側の「PC」を右クリックする。
2. 「ネットワーク ドライブの割り当て」を選ぶ。見つからない場合は「PC」を開き、上部の「…」メニューを確認する。
3. ドライブに`Z:`を選ぶ。
4. フォルダーへ次を入力する。

```text
\\担当1のIPv4アドレス\ProconShare
```

5. 「サインイン時に再接続する」をオンにする。
6. 必要なら「別の資格情報を使用して接続する」をオンにする。
7. 「完了」を押し、前項と同じ資格情報を入力する。

担当2のGUIへ指定する試合用共有フォルダは次になる。

```text
Z:\match-01
```

## 4. 担当3 Macから接続する

1. Finderを前面にする。
2. メニューバーの「移動」→「サーバへ接続」を選ぶ。ショートカットは`command + K`。
3. サーバアドレスへ次を入力する。

```text
smb://担当1のIPv4アドレス/ProconShare
```

例:

```text
smb://192.168.10.21/ProconShare
```

4. 「接続」を押す。
5. 認証画面では「登録ユーザ」を選ぶ。
6. 次を入力する。
   - 名前: `proconshare`
   - パスワード: 2-3で設定したパスワード
7. 必要なら「このパスワードをキーチェーンに保存」をオンにする。
8. Finderのサイドバー「場所」に`ProconShare`が表示され、`match-01`が見えることを確認する。

Mac上では通常、共有フォルダは次の場所へマウントされる。

```text
/Volumes/ProconShare
```

担当3のGUIへ指定する試合用共有フォルダは次になる。

```text
/Volumes/ProconShare/match-01
```

同名の共有を二重接続すると`/Volumes/ProconShare-1`などになる場合がある。Finderで古い接続を取り出してから再接続し、GUIのフォルダ選択ボタンで実際の場所を選ぶ。

`proconshare`だけで認証できない場合は、名前へ`担当1のPC名\proconshare`を入力する。

## 5. 3台で読み書きを確認する

この確認は必ず本番前に行う。フォルダが見えるだけでは不十分で、3台すべてに作成・読取・更新・削除権限が必要である。

1. 担当1が`match-01`内に`test-from-pc1.txt`を作る。
2. 担当2と担当3からそのファイルを開く。
3. 担当2が`test-from-pc2.txt`を作る。
4. 担当1と担当3からそのファイルを開く。
5. 担当3が`test-from-mac.txt`を作る。
6. 担当1と担当2からそのファイルを開く。
7. 各端末で、自分が作ったテストファイルを一度編集して保存する。
8. 各端末でテストファイルを1個ずつ削除する。
9. 最後に`match-01`を空にする。

いずれかの端末で作成や削除ができなければ、本番利用できない。担当1で`proconshare`の共有アクセス許可が「読み取り/書き込み」になっているか確認する。

## 6. GUIへ共有フォルダを設定する

3台は同じ物理フォルダを参照するが、入力するパスはOSごとに異なる。

| 端末 | GUIの「共有フォルダ」へ指定する値 |
|---|---|
| 担当1 Windows | `C:\ProconShare\match-01` |
| 担当2 Windows | `Z:\match-01` |
| 担当3 Mac | `/Volumes/ProconShare/match-01` |

各端末で次を行う。

1. GUIの「実行設定・使用ファイル」を開く。
2. 「共有フォルダ」の選択ボタンを押す。
3. 上表の`match-01`を選ぶ。
4. 3人運用の担当を選ぶ。
5. 問題取得や探索を始める前に、表示された共有フォルダが正しいことを指差し確認する。

作業フォルダは共有しない。3台の`runtime`または作業フォルダは必ず別々にし、「共有フォルダ」だけを同じ場所へ向ける。

## 7. 試合ごとに新しい空フォルダを使う

前試合のチェックポイント混入を避けるため、同じ試合用フォルダを使い回さない。

1. 1試合目は`C:\ProconShare\match-01`を使う。
2. 2試合目の前に、担当1が空の`match-02`を作る。
3. 3台のGUIで共有フォルダを`match-02`へ変更する。
4. 担当2とMacから、新しいフォルダが空であることを確認する。

古い試合フォルダは試合中に削除しない。必要なら全日程終了後に保存または削除する。

## 本番直前チェックリスト

- [ ] 3台が同じスイッチングHUBへ有線接続されている
- [ ] 3台ともWi-Fiがオフになっている
- [ ] 担当1のEthernetがプライベートネットワークになっている
- [ ] 担当1のネットワーク探索とファイル共有がオンになっている
- [ ] 担当1が電源接続され、スリープしない設定になっている
- [ ] 担当1のEthernet IPv4アドレスを当日確認した
- [ ] 担当2の`Z:\match-XX`が開ける
- [ ] Macの`/Volumes/ProconShare/match-XX`が開ける
- [ ] 3台すべてからファイルを作成・読取・編集・削除できる
- [ ] 試合用フォルダが空である
- [ ] 3台のGUIが同じ試合用フォルダを指定している
- [ ] 3台の作業フォルダは別々である
- [ ] 3台のURLとTOKENが同じチーム用になっている

## 接続できないとき

### 担当2とMacの両方から接続できない

共有元側の問題である可能性が高い。次の順で確認する。

1. 担当1が起動中で、スリープしていないか。
2. 担当1のLANケーブルとHUBのリンクランプが点灯しているか。
3. 担当1のIPv4アドレスが変わっていないか。
4. 担当1で`\\localhost\ProconShare`を開けるか。
5. Ethernetがプライベートネットワークになっているか。
6. ネットワーク探索とファイル共有がオンか。
7. Windows Defenderファイアウォールで「ファイルとプリンターの共有」がプライベートネットワークに許可されているか。

ファイアウォール全体は無効化しない。

### 担当2だけ接続できない

1. `Z:`ではなく、まず`\\IPv4アドレス\ProconShare`を直接開く。
2. 「コントロール パネル」→「資格情報マネージャー」→「Windows 資格情報」を開く。
3. 担当1のPC名またはIPv4アドレスに対する古い資格情報があれば削除する。
4. 再接続し、`担当1のPC名\proconshare`と共有用パスワードを入力する。
5. 接続後、`Z:`を割り当て直す。

「ネットワーク名が見えない」場合でも、IPv4アドレスを使った直接接続が成功すれば運用できる。

### Macだけ接続できない

1. Finderの既存`ProconShare`接続を取り出す。
2. `command + K`から`/`区切りの`smb://IPv4アドレス/ProconShare`を入力し直す。
3. 「ゲスト」ではなく「登録ユーザ」を選ぶ。
4. 名前`proconshare`と共有用パスワードを入力する。
5. Finderで開けた後、GUIのフォルダ選択ボタンから`match-XX`を選び直す。

### 読めるが作成・削除できない

担当1で共有設定を開き、`proconshare`のアクセス許可を「読み取り/書き込み」にする。既に正しい場合は、`C:\ProconShare`の「プロパティ」→「セキュリティ」でも`proconshare`に変更・書込み権限があるか確認する。

### 会場で端末間通信そのものが遮断されている

3台が競技サーバーへ接続できるのに、正しいIPv4アドレスと共有設定でもSMBだけ接続できない場合は、競技ネットワークが端末間通信を遮断している可能性がある。設定を連続変更せず、審判またはネットワーク担当者へチーム内端末間のTCP 445通信が許可されているか確認する。

## やってはいけないこと

- Windows Defenderファイアウォール全体を無効化しない
- `C:\`全体、ユーザーフォルダ全体、リポジトリ全体を共有しない
- 共有アクセス許可を不特定の`Everyone`へ開放しない
- 共有専用ユーザーを管理者にしない
- Wi-Fi、テザリング、クラウドストレージを代用しない
- 3台で同じ作業フォルダを直接使用しない
- 試合中に共有元PCをスリープ、再起動、ログオフしない
- 接続不良を直すために回答を競技サーバーへ再送しない
